# ACR1552U 配置扩展验证（2026-11-12）

独立工作树分支 `codex/acr1552-uid-options`，基于已提交的 `2685a69`。本次仅扩展 ACR1552U 原生进程及教师设置，不合并主工作树正在处理的其他分支。

## 功能

- UID 字节顺序：保持响应顺序 / 反转四字节；仅对成功的四字节响应做映射。
- PC/SC 协议：自动协商 / T=0 / T=1；访问模式：共享 / 独占。
- 旧配置和旧 CLI 参数继续默认为正序、自动、共享，固定取 UID APDU 不变。
- 新设置通过严格 schema 和独立进程参数传递；不回填旧设置，不增加真实卡号展示或持久化。
- 数据源“卡号表示”已有十进制选项，本次复用。界面固定示例：`01020304 → 16909060`；四字节反序后 `04030201 → 67305985`。

## 实机待验证

本轮未验证实际 ACR1552U、两张学生卡及学校 Concard 数据库之间的映射，不能据上述测试确认现场问题已解决。

1. 在“设置 → 校园数据源”完整填写新配置，卡号表示选“无符号十进制”，覆盖服务端配置。输入发送后沿用原有清空规则。
2. 在“读卡器”选择 ACR1552U-M1，刷新并选中 PICC 设备；先保留响应顺序、自动协商、共享和 250ms，再覆盖并启动。
3. 在“使用登记”分别刷两张已知学生卡，核对姓名、班级及登记/结束。用现场已知 UID 与数据库卡号对照确认字节序；只有映射明确需要时才选择反序，并统一所有教师端设置。
4. 字节序改变会改变学生哈希 ID，旧历史不会自动迁移。7/10 字节 UID 继续拒绝，不能靠截断变成四字节。
