# 教师端界面与 cyez-ui 接入

界面库已确定为 [lmyzzzz/cyez-ui](https://github.com/lmyzzzz/cyez-ui)，核对提交 `0a1d4f4fa9affecb2eaf83e978c1e9b1557c7043`（2026-10-28）。UI 库负责外观和窗口能力；业务页面、刷卡、网络、身份、数据库、日志和更新由本项目实现。

![界面结构](teacher-ui.svg)

## 页面与行为

| 页面/组件 | 显示内容 | 行为和错误状态 |
| --- | --- | --- |
| AppShell | 产品名称、账号/角色、导航、服务器在线/离线、当前机房范围、刷新时间 | 无账号只能登录/诊断；管理入口按权限显示，服务端仍重新鉴权 |
| 设备列表主页面 | 使用中 / 未使用选项卡；机房和标签筛选、分页；已选数量；结束选中/结束全部 | 唯一允许刷卡自动跳转的页面；使用中显示设备、开始时间、学生姓名、备注与手动结束；未使用区将可分配和禁用清楚区分 |
| StudentSummary | 候选姓名、班级、校内学号、身份查询状态 | 字段 TBD-01；不展示 raw UID、HMAC 或学籍号；字段缺失用明确占位，不编造值 |
| 登记页 | StudentSummary、刷卡时间、备注、DevicePicker、确认/取消、5 秒取消倒计时 | 未选设备或资料不完整不可提交；编辑/失焦暂停倒计时；提交冲突保留合理输入并显示最新可选设备 |
| DevicePicker | 设备名/编号、机房、标签、空闲/使用中/禁用；可搜索分页 | 空闲可选，禁用不可选；“结束占用”需单独确认、权限与服务端成功后刷新才能选中；若释放时间晚于本次刷卡则要求重刷，避免记录重叠，不偷偷改开始时间 |
| 刷卡结束页 | 当前学生资料、设备、开始/结束时间、已有备注、确认/取消、5 秒确认倒计时 | 到期与手点共用一次提交；编辑/失焦暂停；提交失败/过期停止自动提交 |
| 单设备结束 Modal | 与结束页共用表单，默认加载已有备注 | 手动操作不自动确认；焦点限制/关闭恢复；其间刷卡只 Toast |
| 批量结束 Modal | 固定紧凑设备/学生/开始时间列表、范围与条数、空的公共备注框、显式确认 | 公共备注仅追加；版本变更整批冲突；超过单批上限显示分批状态；处理中不能靠关窗制造重复任务 |
| 记录查询/更正 | 时间/学生/设备筛选、分页导出、备注和结束原因 | 旧记录显示当前资料；更正/作废需 admin+原因；不会给普通教师开放数据库 CRUD |
| 档案/设备/标签管理 | 单条/批量预览、字段校验、版本冲突、归档说明 | 学生最终表单与导入模板 TBD-01；管理页面刷卡只 Toast |
| 设置/诊断 | 读卡连接、服务器地址/证书状态、应用版本、待传日志数量 | 无秘密显示；读卡协议 TBD-03；不允许 UI 任意加载驱动或执行 shell |

输入门控始终先判断当前路由和 Modal/提交状态，再决定是否发送 `/scan-previews`；被忽略的刷卡不触发校园 API，也不缓存原始卡号。设备状态刷新不会突然把用户正在编辑的表单替换成另一位学生；新 scan 到达登记/结束页只 Toast 并要求回主页面重刷。

快速交互仍须可访问：键盘可到达所有操作，Modal 焦点正确，危险批量操作有范围提示，状态不只靠颜色，倒计时可见且可暂停/取消，系统减少动态效果偏好生效。不得把 cyez-ui 的展示页测试当本项目登记页测试。

## 包与 Yarn 工作区边界

![UI 与工作区依赖](ui-workspaces.svg)

| 已核对上游包 | 入口与能力 | 项目用法 |
| --- | --- | --- |
| `@series/ui@0.1.0` | React UI、`/theme`、`/bootstrap`、`/styles.css`、`/app.css`、`/appearance-init.js` | 本项目 `packages/ui` 提供主题、导航适配与业务组件封装，renderer 消费；不供 server 引用 |
| `@series/electron@0.1.0` | `/main`、`/preload`、`/shared` 分离入口，窗口控制/状态同步 | main 和 preload 仅引用对应入口；业务 IPC 独立定义并验证 sender，不把 main bundle 导入 renderer |
| peer 依赖 | UI：React/React DOM `>=19 <20`、router `>=7 <8`；Electron 包：`>=39 <45` | 由应用显式声明并固定兼容版本，确保单份 React；最终 Electron 版本经 Windows/安装器测试决定 |

上游 pnpm 项目尚未在 npm 发布包，采用构建 tarball。实施时由受信任构建流程在固定上游提交构建并产出 `series-ui-0.1.0.tgz` 与 `series-electron-0.1.0.tgz`，记录源 commit、校验和与 LICENSE/NOTICE；项目通过受控制品或 `vendor/` 固定包消费，Yarn lockfile 记录校验。不能把 GitHub repo URL 当已构建 npm 包，不从浮动 main 在线安装生产依赖。

本项目内部依赖继续使用 `workspace:^`，UI 封装包可对外部 tarball 使用 `file:` 依赖；适配包构建不复制业务逻辑。上游采用 pnpm 不要求消费项目改 pnpm，本项目只保留一个 Yarn lockfile。消费验收必须从干净目录安装、构建、检查单份 React、验证 preload 分离与打包运行，而非引用上游 node_modules 的偶然依赖。

在 renderer 保持 `sandbox=true`、`contextIsolation=true`、`nodeIntegration=false`；preload 仅暴露刷卡订阅、受控业务动作、必要窗口功能和日志接口。main 负责认证及网络，服务端承担业务最终判断。页面不允许任意外部导航、新窗口或直接校园卡 API 请求；UI 更新不能扩大 IPC 权限。

上游 NOTICE/许可证未将原代码重新授权为开源，许可/分发输入记为 TBD-06，本轮不复制源码。上游验证记录包含单元、浏览器和部分 Windows Electron 检查，但安装/卸载、不同 DPI/多显示器等仍有未验证边界；本项目必须独立验收。
